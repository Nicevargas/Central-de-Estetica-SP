# Imagens para o Instagram

Coloque aqui as fotos (.jpg) que serão publicadas pelo GitHub Actions
**Publicar no Instagram** e informe o caminho no campo "Imagens",
por exemplo `instagram/promo-limpeza-de-pele.jpg`.

- 1 imagem = post simples; 2 a 10 = carrossel (na ordem informada)
- Formato JPEG; ideal 1080×1350 (retrato 4:5) ou 1080×1080
- Links públicos `https://...` também funcionam no lugar de arquivos
